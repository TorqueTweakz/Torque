Features

Everything in TORQUE, in one place

TORQUE combines system tuning, per-game configuration and measurement tools in a single application, with backups and a full activity log throughout.

Guided optimization

Four levels, from conservative to experimental, each with a complete preview.

  • Previews every old → new value and every automation
  • Optional restore point and temporary-file cleanup
  • Rolls back automatically if a change fails

Per-game configuration

Detects supported games and writes tuned values into the game's own settings file, only while the game is closed and always with a backup.

  • Fortnite, VALORANT, CS2, Apex Legends, Rocket League, Marvel Rivals, Minecraft
  • Fortnite presets: Competitive, Balanced and Visual (DX12)
  • Custom per-game setups and profiles for any executable

NVIDIA driver tuning

Settings are written to the NVIDIA driver profile database for each game, and can be restored to your exact original values.

  • Low Latency Mode, V-Sync off, unlimited shader cache
  • Prefer Maximum Performance per game
  • AMD systems receive Windows, game and network tuning

Stretched resolution

Create and switch to a stretched resolution in one step, with safeguards if the display does not accept it.

  • 1750×1080, 1650×1080, 1440×1080 and 1280×1080
  • 15-second keep-or-revert confirmation
  • Optional auto-stretch only while Fortnite is running

Benchmark Lab

Measure the effect of any change using Intel PresentMon, which is bundled and checked against its official SHA-256 before each run.

  • Average FPS, 1% and 0.1% lows, stutter rate
  • Frame-time graph
  • Saved Before / After comparisons with percentage change

Health Check

Identifies the configuration issues that usually matter most, many of which are outside Windows itself.

  • Refresh rate, RAM speed (EXPO/XMP) and Resizable BAR
  • Monitor connected to the GPU rather than the motherboard
  • Driver age, GPU scheduling, power plan, page file and more

Network tools

Evaluate and select a DNS provider, and measure connection quality.

  • DNS benchmark with one-click switch and restore
  • Ping, jitter and packet-loss test
  • Flush DNS cache

Personalization

Adjust TORQUE's appearance and behavior to suit your setup.

  • Accent colors, animated backdrops and sound packs
  • Color Enhancer with NVIDIA Digital Vibrance and before/after view
  • Low Performance mode for older PCs and virtual machines

Backups & restore

Every change set is stored with its original values and can be reverted individually or all at once.

  • TORQUE on/off switch returns the PC to stock
  • System Restore point integration
  • Activity log, exportable to a text file

Access control & sharing

Optional controls for shared PCs, and a way to share a configuration without sharing personal data.

  • Optional password (salted PBKDF2-SHA256)
  • Export and import .torque setup profiles
  • No passwords, backups or file paths in exported profiles
Evidence ratings

Honest about what each tweak does

Every entry in the Tweak reference is rated Proven, Situational or Experimental within the application, and carries its risk level and whether a restart is required. Windows tweaks typically improve consistency (1% lows and background interruptions) rather than average FPS. The largest gains usually come from the Health Check items and from Fortnite's Performance rendering mode.

Measure your own system. Results vary by hardware, drivers and game. Use Benchmark Lab to compare before and after, and revert anything that does not help.
