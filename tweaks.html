What TORQUE changes

Every tweak, in plain English.

47 tweaks in Free and 19 in Plus. Each one is previewed with its old and new value before it's applied, and each can be reverted on its own.

Background

Windows Error Reporting off

MEDSITUATIONAL

Stops Windows collecting and sending crash reports to Microsoft.

Details
Why
When something crashes, Windows can spend CPU and disk building and uploading reports. Turn it back on if Microsoft support ever asks for reports.
Impact
No crash-report uploads or report queues in the background
Restart
No
Changes
  • HKLM\SOFTWARE\Microsoft\Windows\Windows Error Reporting\Disabled

Group Windows services (far fewer svchost processes)

MAXPROVEN

Sets SvcHostSplitThresholdInKB to your installed RAM so Windows groups its services into shared svchost.exe processes again, like Windows 10 1607 and older did. This is the main reason other tweakers show ~110 processes.

Details
Why
On PCs with more than 3.5 GB of RAM Windows runs almost every service in its own svchost process (often 70–90 of them). Grouping them cuts the count a lot. Trade-off: if one grouped service crashes it can take its neighbours down with it, so revert this if you ever see odd service errors. Takes effect after a restart.
Impact
Roughly 40–60 fewer processes and a little less RAM. Mostly a cleaner process list — FPS change is small
Restart
Yes
Changes
  • HKLM\SYSTEM\CurrentControlSet\Control\SvcHostSplitThresholdInKB

Windows Search indexer to Manual

MAXSITUATIONAL

Sets the Windows Search indexing service (WSearch) to Manual. Start-menu app search keeps working; searching file contents and Outlook search get slower.

Details
Why
The indexer wakes up and reads/writes your drive in the background — exactly the kind of spike that hurts 1% lows. Gamers who don't search their files lose nothing.
Impact
No background indexing CPU/disk spikes; file search inside folders gets slower
Restart
No
Changes
  • Service WSearch → Manual
