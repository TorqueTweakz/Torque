Install

Up and running in five minutes.

Windows SmartScreen may say "Windows protected your PC" because TORQUE isn't code-signed yet. Check the SHA-256 above, then choose More info → Run anyway.
  1. Extract the zipRight-click → Extract All. Keep the folder somewhere permanent, like C:\Tools\TORQUE.
  2. Run Torque.exeAccept the administrator prompt. It's needed to change system settings.
  3. Set a password or skip itOptional. It only protects the app from casual access.
  4. Fix what Health check findsThen record a Before run in Benchmark.
  5. OptimizePick a level, review the preview, apply. Restart if asked, then record an After run.

Updating from an older version

Close TORQUE (also from the tray), replace the old folder with the new one and start it. Settings, backups and benchmark runs live in %ProgramData%\Torque and carry over. To remove TORQUE completely, first use Backups → Revert everything and restart, then delete the folder and %ProgramData%\Torque.
