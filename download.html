Installation

Get started in a few minutes

  1. Download and verify. Download TORQUE-v2.4.zip and, ideally, verify its checksum.
  2. Extract the archive. Right-click the zip and choose Extract All. Place the folder somewhere permanent, for example C:\Tools\Torque\.
  3. Run Torque.exe. Accept the administrator prompt. Administrator rights are required to change system settings.
  4. Handle the SmartScreen prompt. If Windows shows "Windows protected your PC", select More info, then Run anyway. Why does this appear?
  5. Set a password, or skip it. Create a startup password, or choose Continue without a password. Accept the offer to create a System Restore point.
  6. Run Health Check and record a baseline. Resolve any items flagged red, then record a Before run in Benchmark Lab using the same scene you will test afterwards.
  7. Optimize. Open the Optimize page, choose LOW, MED or MAX, review the preview and click Optimize. Restart when prompted, then record an After run to compare.
Uninstalling

Removing TORQUE

First switch TORQUE tweaks off (or use Backups & Restore → Revert everything) and restart, so your settings return to stock. Then delete the TORQUE folder. Configuration and backups are stored in %ProgramData%\Torque\ and can be deleted once you no longer need them.
