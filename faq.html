FAQ

Frequently asked questions

Answers to common questions about performance, safety and support. If you cannot find what you need, ask in the community.

General

Is TORQUE free?

Yes. TORQUE is free during the public beta. A paid version is planned for the future, and versions you download now will continue to work.

Which systems are supported?

Windows 10 and 11 (64-bit). Automatic driver tuning is NVIDIA-only for now; on AMD graphics cards, Windows, game and network tuning are fully available.

Do I need an account?

No. There is no account system and no sign-in. You can optionally set a startup password on the machine.

Performance

How much FPS will I gain?

It depends on your hardware and game. The largest improvements usually come from the Health Check items (monitor refresh rate, RAM running at its rated EXPO/XMP speed, Resizable BAR) and from Fortnite's Performance rendering mode. Windows tweaks mostly improve consistency, meaning steadier frame times and fewer background interruptions, rather than a large jump in average FPS. Benchmark Lab lets you measure the difference on your own PC.

Why do some tweaks say Experimental or Disputed?

We rate each tweak by the strength of the evidence behind it. Tweaks with mixed evidence are not applied by default and are only included at the ULTRA level. Benchmark them and revert any that do not help.

Does TORQUE work in a virtual machine or on an older PC?

Yes. TORQUE automatically switches to Low Performance mode in virtual machines, remote desktops and on PCs without full GPU rendering. You can also select it manually under Personalize → Performance.

Safety

Is it safe? Why does Windows warn me?

The beta is not yet code-signed, so Windows SmartScreen reports it as an unrecognized app, and some antivirus products use heuristic rules against unsigned tools that request administrator access. We recommend that you verify the checksum and scan the file before running it. Details are on the Security page.

Can it damage my system?

TORQUE only changes documented settings, previews each change, creates a restore point and backs up original values. Failed changes roll back automatically, and you can revert everything at any time. As with any tool that changes system settings, you should still use it with care, particularly at the ULTRA level.

Can I get banned in online games?

TORQUE does not inject into games, read game memory or modify game binaries; it only edits each game's own settings file and Windows/driver settings. Anti-cheat services are on its protected list. That said, anti-cheat rules are set by each publisher and can change, so we cannot offer a guarantee. Use it at your own discretion.

How do I undo everything?

Switch TORQUE tweaks off in the sidebar, or choose Backups & Restore → Revert everything, then restart.

What data does TORQUE collect?

None. There is no telemetry. The only network use is the optional DNS benchmark and ping test. See the Privacy page.

Support

I found a bug. What should I send?

Open Settings → About → Activity log and export it, then share it with a short description and a screenshot in the support channel.

Where can I ask questions or suggest features?

Join the Discord server. Feature requests are discussed there openly.
