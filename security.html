Security & transparency

Verify TORQUE before you run it

TORQUE requires administrator rights and changes system settings, so you should not take our word for what it does. This page explains how it behaves and how to check the download independently.

Summary

What you should know first

Changes are visible

TORQUE modifies documented registry values, power-plan settings, services (set to Manual, never Disabled), driver profiles and games' own settings files. Each change is previewed before it is applied.

Changes are reversible

A System Restore point is offered first, original values are backed up, and failed changes roll back automatically.

The build is unsigned

The beta is not yet code-signed, so Windows SmartScreen and some antivirus products will warn about it. We explain this below rather than hide it.

Verification

Check the download yourself

We recommend completing at least the first two steps before running TORQUE for the first time.

  1. Verify the checksum. Confirm that the file you downloaded is identical to the file published here. In PowerShell: 
    Get-FileHash .\TORQUE-v2.3.zip -Algorithm SHA256
    or in Command Prompt: 
    certutil -hashfile TORQUE-v2.3.zip SHA256
    The result must match this value exactly:
    fbc66840afe4d8cbeeaf497493464eee2e8a04949b43feb3770c830b5ca15468
  2. Scan it with multiple engines. Upload the zip to VirusTotal, or look up this file's hash to see whether it has already been analyzed. Because the application is unsigned and edits system settings, a small number of generic or heuristic detections is possible; see "Warnings you may see" below.
  3. Test in isolation (optional). If you want additional assurance, run TORQUE inside Windows Sandbox or a virtual machine first. TORQUE detects virtual machines and switches to Low Performance mode automatically.
  4. Review before you apply. Nothing is changed until you click Apply, and the preview lists every setting. The complete catalogue is also published in the Tweak reference.
Behavior

What TORQUE does and does not do

What TORQUE does

  • Changes documented settings only: registry values, power plans, services, driver profiles and game settings files
  • Previews every change with its old and new value
  • Offers a System Restore point before applying
  • Backs up original values once, before the first change, so a revert always returns to your real original state
  • Records every action in the Activity Log, which can be exported
  • Verifies bundled third-party tools (PresentMon, ViVeTool) against known checksums before use

What TORQUE does not do

  • Does not disable Windows Defender, SmartScreen, UAC, Windows Update or CPU security mitigations; these are blocked in code
  • Does not inject into games, read game memory or modify game binaries
  • Does not use registry "cleaners" or mass-disable services
  • Does not require an account and does not collect telemetry
  • Does not modify anti-cheat, audio, NVIDIA, Logitech or game-server software; these are on a protected exclusion list

A note on anti-cheat. TORQUE does not interact with game processes. It edits each game's own configuration file, as you could by hand in the game's menu. However, anti-cheat policies are set by each publisher and can change, and no third-party tool can guarantee compliance. Use TORQUE at your own discretion.

Warnings you may see

Windows SmartScreen and antivirus alerts

The TORQUE beta is not yet signed with a code-signing certificate. Certificates are a recurring cost, and SmartScreen additionally builds a reputation for each publisher over time. As a result, new applications from independent developers commonly trigger the following warning.

  1. When Windows shows "Windows protected your PC", select More info.
  2. Confirm that the publisher and file name are what you expect, then select Run anyway.

A warning from SmartScreen means the file is unrecognized, not that it has been identified as malicious. If you are not comfortable proceeding, do not run the file; ask questions in our Discord server first.

Antivirus detections. Some security products flag unsigned tools that request administrator access and edit system settings, using generic or heuristic rules. If you see a detection, check the specific name reported and the number of engines involved on VirusTotal, and feel free to send us the report. A signed build is planned for the paid release.

Data & network

What leaves your PC

TORQUE has no account system and no telemetry. Its only network activity is the optional DNS benchmark and ping test, plus links you choose to open. Configuration, backups, the activity log and benchmark results are stored locally in %ProgramData%\Torque\.

The optional startup password is a casual-access lock rather than strong security: only a salted PBKDF2-SHA256 hash is stored, and anyone with administrator rights can reset it.

Reverting

Returning to stock

Switch TORQUE tweaks off in the sidebar, or choose Backups & Restore → Revert everything, then restart. Your PC returns to its original configuration. The Windows System Restore point provides an additional fallback.

For a complete list of everything that can be changed, see the Tweak reference.

Responsible disclosure

Found a security concern?

If you believe you have found a vulnerability or something in TORQUE that behaves unexpectedly, please tell us through the community support channel. Include the Activity Log export (Settings → About → Activity log) and, where relevant, the VirusTotal link.
