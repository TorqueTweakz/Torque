Safety & security

Built to be undone.

What TORQUE does to protect your PC, what it will never do, and how the download and Plus licensing are protected.

Preview everything

Every change shows the current value and the new one before it's made. Untick anything you don't want.

Back up everything

A restore point and a copy of every original value come first. Originals are captured once, so revert always means "how my PC was".

Roll back failures

If Windows blocks part of a change, the whole tweak is rolled back and you get a plain-language reason.

TORQUE never

  • disables Defender, SmartScreen, UAC or Windows Update
  • turns off CPU security mitigations or forces HPET
  • sets services to Disabled (only Manual, so they still start when needed)
  • injects into games, reads game memory or hooks input
  • downloads or installs anything by itself
  • sends telemetry (an optional anonymous user counter is off by default)

Download and update protection

  • SHA-256 for every download on this site
  • Signed update file. The app only trusts update info signed with TORQUE's offline key, so a hijacked site can't push a fake download link.
  • Bundled tools are verified (PresentMon, ViVeTool) against their official hashes before each use.
  • Free contains no Plus code. Plus tweaks are sent only to activated PCs, signed and bound to that PC.
  • Keys are stored encrypted for your Windows account. Activation sends only the key and a hashed PC id.

Why antivirus or SmartScreen may warn

TORQUE isn't code-signed yet, and it asks for administrator rights to change system settings. Some antivirus products flag unsigned tools that do that. Check the SHA-256 on the download page, scan it on VirusTotal if you like, and only ever download it from this site or the TORQUE Discord.

Online games and anti-cheat

TORQUE changes Windows and driver settings and writes each game's own settings file while the game is closed. It never touches a running game. The optional crosshair is a transparent window drawn on top; some tournaments don't allow crosshair overlays, so check your game's rules.

Reporting a problem

Open a ticket in the Discord with your TORQUE version and the SHA-256 of your file.
