Should I trust it?

Fair question — TORQUE asks for admin rights and changes system settings. Here's exactly what it does, what it never does, and how to check for yourself.

NOT A VIRUS

TORQUE only changes documented Windows, driver and game settings — and shows you each one, with its old and new value, before it changes anything. Every change is saved so it can be undone.

✓ What TORQUE does

  • Changes documented settings only: registry values, power plans, services (set to Manual — never Disabled), driver profiles, your games' own settings files
  • Previews every old → new value before applying
  • Creates a System Restore point first
  • Backs up every original value, and rolls back automatically if a change fails
  • Logs every action in the Activity Log

✕ What TORQUE never does

  • Never disables Windows Defender, SmartScreen, UAC, Windows Update or CPU security mitigations
  • Never injects into games, reads game memory or edits game files — anti-cheat safe
  • No registry "cleaners", no mass-disabling services, no HPET myths
  • No tracking: no account, no telemetry — the only network use is the optional DNS speed test
  • Never touches anti-cheat, audio, NVIDIA, Logitech or game-server apps

"Windows protected your PC"?

You'll probably see this on first launch. It doesn't mean TORQUE is dangerous — it means the beta isn't code-signed yet. Signing costs money and builds reputation over time, so brand-new apps from small developers trigger it. A signed build comes with the paid version.

FAQ

How much FPS will I gain?

It depends on your PC. The biggest wins are usually Fortnite's Performance mode, RAM running at its rated speed (EXPO/XMP — TORQUE detects this), and your monitor's refresh rate. Windows tweaks mostly mean steadier frames and lower delay rather than a huge average-FPS jump. Use Benchmark Lab to measure your own before/after.

Can I get banned?

TORQUE doesn't inject into games, read game memory or modify game files — it only edits each game's own settings file (like changing settings in the menu) and Windows/driver settings. Anti-cheat services are on its protected list.

Is it really free?

Yes — free while it's in beta. A paid version is planned later. Anything you download now keeps working.

Does it work on AMD graphics cards?

Yes for Windows, game and network tuning. Automatic driver tuning is NVIDIA-only for now.

How do I undo it?

Switch TORQUE tweaks off in the sidebar (or Backups & Restore → Revert everything) and restart.

It's laggy in a virtual machine / old PC

TORQUE switches to Low Performance mode automatically there. You can also pick it in Personalize → Performance.

Found a bug?

Settings → About → Activity log shows everything TORQUE did. Send a screenshot of it along with what happened.
