How it works

A predictable process, from first scan to final result

TORQUE is designed so that you always know what is about to change, and can always go back.

1. Measure

Run a Health Check and record a baseline in Benchmark Lab. Frame times are captured with Intel PresentMon so you have real numbers to compare against.

2. Preview

Choose an optimization level. TORQUE lists every setting it will change, showing the current and new value, before anything is applied.

3. Apply and verify

TORQUE creates a restore point, backs up original values and applies the changes. Run the benchmark again to confirm the difference on your own hardware.

Optimization levels

Choose how far to go

Each level builds on the previous one. Start with LOW or MED; ULTRA is intended for experienced users and includes a warning and a restart.

LOW

Essential, low-risk changes: maximum refresh rate, NVIDIA low-latency driver profile and Game Mode. No forced restarts.

MED

Adds USB, PCIe and CPU latency power settings, curated debloat, startup cleanup and balanced game configurations.

MAX

Adds the Windows Low Latency Profile, a faster DNS provider, competitive game configurations and Game Boost.

ULTRA

Adds experimental tweaks and hardware GPU scheduling. Shows a warning first and requires a restart.

Capabilities

Built around the things that affect gaming performance

Per-game configuration

Detects Fortnite, VALORANT, CS2, Apex Legends, Rocket League, Marvel Rivals and Minecraft, and writes tuned values into each game's own settings file.

NVIDIA driver profiles

Configures Low Latency Mode, V-Sync, shader cache size and power management per game through the driver profile database.

Game Boost

While a profiled game runs, TORQUE switches the power plan, raises game priority and pauses background apps you approve. Toggle it with Ctrl+Alt+B.

Stretched resolutions

Creates 1750×1080, 1650×1080 and other resolutions through the NVIDIA driver API, with an automatic revert if you do not confirm the change.

Benchmark Lab

Measure average FPS, 1% and 0.1% lows and stutter rate, and keep Before/After comparisons.

Complete activity log

Every change is timestamped and exportable, so you can always see what TORQUE did and when.

Security & transparency

Designed to be inspected, not trusted blindly

TORQUE requires administrator rights because it changes system settings. For that reason we publish the exact list of every change it can make, a SHA-256 checksum for each release, and clear guidance on how to scan and verify the download yourself.

Read the security overview

  • Preview before apply. Each change is shown with its old and new value.
  • Restore point and backups. Original values are captured before the first change.
  • No Defender, UAC or Windows Update changes. These are blocked in code.
  • No telemetry or account. Network use is limited to the optional DNS and ping tests.
  • Published tweak list. All 51 tweaks, documented.
