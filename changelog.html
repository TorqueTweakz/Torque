Changelog

Release notes

A summary of notable changes in each TORQUE release.

v2.4Current beta

Added

  • Process diet (MAX). Windows services are grouped into shared svchost processes again (sized to your RAM), which typically removes 40–60 processes after a restart. The Windows Search indexer goes to Manual and Store apps are blocked from running in the background through Group Policy.
  • More services set to Manual, never Disabled: Program Compatibility Assistant, Storage Service, Offline Files, Internet Connection Sharing, Parental Controls monitor and the Adobe updater (if installed). The Print Spooler goes to Manual only if no real printer is found.
  • Game Boost efficiency mode. While a game runs, browsers, launcher web helpers, sync tools, Phone Link and Widgets are put into Windows Efficiency mode at below-normal priority, then restored when you quit. Discord, OBS/Medal and protected apps are never touched. Standby RAM is cleared only when free memory runs low.
  • Games start at High priority (Fortnite, CS2, Apex, Rocket League, Marvel Rivals) through Windows' Image File Execution Options. VALORANT is left alone.
  • Fortnite renderer A/B in Benchmark Lab: switch between Performance (DX12) and Legacy Performance (DX11) and compare them on your own PC.
  • ULTRA: Memory Integrity / VBS off (opt-in security trade-off, ~3–6% FPS measured by Tom's Hardware). Skipped automatically if Riot Vanguard or FACEIT is installed; Health Check turns it back on in one click if you install them later.
  • Process counter on the Dashboard: processes now vs. before TORQUE, with a breakdown of what's still running.

Fixed

  • Fortnite's rendering mode: since v37, Performance mode runs on DirectX 12. TORQUE was selecting the old DX11 version, which is now called "Legacy Performance". It now defaults to the current Performance mode, with Legacy DX11 available as an option.
  • More auto-start apps are turned off (Overwolf, CurseForge, Lively, Creative Cloud, Grammarly; Zoom at MAX).
v2.3Previous release

Added

  • TORQUE on/off switch in the sidebar. Switching it off reverts everything TORQUE changed and returns the PC to stock, which is useful for recording a baseline.
  • ULTRA level above MAX, including all experimental tweaks and hardware GPU scheduling. Shows a warning first and offers a restart afterwards.
  • Custom setups per game. Choose each setting individually (rendering mode, shadows, Reflex, V-Sync and more). Saved per game and used by Auto-configure and Optimize.
  • Loading indicators throughout, with spinners on buttons plus a progress bar and status pill.

Changed

  • LOW, MED and MAX no longer include hardware GPU scheduling, since it requires a restart.

Fixed

  • Graphics page error on second visit.
  • The level now returns to STOCK when everything is reverted.
  • Tweaks that already match Windows' own setting now display “Windows already set”.
  • Color sliders now always respond; moving them turns gamma on.
v2.2Permissions

Added

  • Permission handling. TORQUE checks for administrator rights and offers to restart as administrator. Changes blocked by Windows are rolled back with a plain-language reason and a suggested fix.
  • Share your setup. Export and import .torque profiles without passwords, backups or file paths.
  • Global shortcuts that work in-game: Ctrl+Alt+B toggles Game Boost and Ctrl+Alt+T opens TORQUE. These can be disabled in Settings.

Changed

  • Each install now creates its own password or skips it; there is no shared default.
v2.1Efficiency

Added

  • Low Performance mode (Personalize → Performance: Auto / Low performance / Full quality). Auto enables it in virtual machines, remote desktops and on PCs without full GPU rendering.

Improved

  • Under software rendering, dashboard CPU use fell from roughly 183% of a core to about 7%, the lock screen from roughly 130% to about 3%, and memory use dropped by about 135 MB.
  • Animated backgrounds pause when TORQUE is not the active window, statistics stop polling when the window is hidden, and memory is returned to Windows on minimize.
  • Temperature queries run every 5 seconds instead of every second, and the executable is precompiled (ReadyToRun) for faster launch.
v2.0Latency tweaks

Added

  • Windows Low Latency Profile (MAX) via hash-checked ViVeTool, on supported builds.
  • USB selective suspend off, Edge background mode off and fastest keyboard repeat.
  • PCIe link power management, CPU energy preference and network adapter power-saving tweaks.
  • Opt-in experimental tweaks: interrupt moderation off, GPU MSI mode, memory compression off and QoS DSCP 46 for games.
