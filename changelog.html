Changelog

What's new.

v2.7
Free and Plus

New

  • A new look across the whole app, with labelled navigation and a Tools hub.
  • TORQUE Plus: a separate build with ULTRA, a 19-tweak Plus pack, Bottleneck Doctor, Game Boost Pro, custom presets, share codes and crosshair extras.
  • Crosshair overlay (Ctrl+Alt+X), click-through and borderless-friendly.
  • Your PC shows the top three fixes for your PC first.
  • Ten new free tweaks, including startup delay off, Recall off, lock-screen ads off and hibernation off (desktops only).
  • Evidence filter in Tweaks and a delete button on benchmark runs.

Security

  • Update info is now signed. The app ignores any update file that isn't signed with TORQUE's offline key.
  • The Free download contains no Plus code. Plus tweaks are sent only to activated PCs, signed and bound to that PC.
  • Tweaks from older versions that moved to Plus can still be reverted in Free.

Changed

  • ULTRA, the experimental tweaks, timer resolution, efficiency mode and standby clean-up moved to Plus. Anything you already applied stays applied and can be reverted.
v2.5
Previous release
  • Update banner with notes and the official checksum.
  • Timer resolution in Game Boost.
  • Copy diagnostics button for support.
  • LOW / MED / MAX / ULTRA level filter; CPU temperature fix.
v2.4
Process diet
  • Service grouping at MAX (typically 40 to 60 fewer processes after a restart).
  • More services to Manual, never Disabled.
  • Game Boost efficiency mode and High priority for supported games.
  • Fortnite renderer A/B in Benchmark Lab; ULTRA Memory Integrity option with anti-cheat checks.
v2.3 and earlier
Foundations
  • TORQUE on/off switch, ULTRA level, custom game setups (2.3).
  • Permission handling, share files, global shortcuts (2.2).
  • Low performance mode (2.1).
  • Latency tweaks and the Windows Low Latency Profile (2.0).
